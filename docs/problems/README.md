为什么单独建这个目录：代码的 commit diff 只能看出「改了什么」，看不出「为什么改」。
而判断一个工程决定的好坏，靠的正是后者——尤其是在几次「不改代码、改判据」的决定上
（承认扫描件比例、拒绝绕过证书校验、承认两路召回可靠性不同），这些都不会出现在 diff 里。
