## 四、已知局限

1. **页码口径**：严格命中要求条款正文前 40 字连续出现在某一页上，跨页条款与含页眉页脚的页面必然判失败，因此以区域命中为主要参考。
2. **超长条款**：切分后的片段继承父条款的页码范围，因此片段级引用只能给到条级页区间，无法精确到片段所在页。
3. **表格条款**：表格单元格在 PDF 提取时按列错序，条款文字与阅读顺序不一致，这类条款需在评测集中单独标记，不能用来测引用准确率。
4. **扫描件**：5 份纯扫描件未做 OCR。若后续要纳入，会同时引入 OCR 错误与版面噪声，需要在 D3 评测集定稿前决定是否补 OCR。
